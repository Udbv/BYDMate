## BYDMate Waze 4.1.0-dev.23 (development pre-release)

### Fixed
- HUD lanes: which arrow of a lane is lit. In a lane with two directions Waze draws the route's
  arrow bright and the other grey; the app took the direction from the manoeuvre instead, and at
  a roundabout the manoeuvre names none, so the first one, «straight», went out (31.10: before
  a roundabout's third exit the «straight and left» lane reached the HUD with «straight» lit).
  The lane's direction is now the branch Waze lit (at least 40 luma brighter than the rest); the
  manoeuvre only when the branches look alike. The `LANES pixels` log line carries each branch's
  brightness and the chosen direction.
- The HUD arrow flipped between two manoeuvres (4.1.0-dev.22): while Waze shows lanes instead of
  the arrow, the arrow read before them was kept even after Waze's text named the next
  manoeuvre (31.10 13:45: «roundabout» and «straight» alternated every second). It is now kept
  only while the manoeuvre has not changed.
