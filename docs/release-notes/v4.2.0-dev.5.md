## BYDMate Waze 4.2.0-dev.5 (development pre-release)

### Added
- Parked route test for ADAS (#53, #23). Under a built route the map page has a button «Маршрут в
  ADAS (тест на стоянці, 30 с)»: the route's first 20 km go to the driving computer the way the
  factory map sends one (navigation status, `naviSDRouteNotify` with the route as JSON, the chosen
  path, the car's place on it), every 200 ms for 30 seconds. The question is whether the ADAS
  screen draws such a route: AutoNavi road ids are unknown outside China and go out empty. The
  same guards as the limit test: P and standing only, checked on every frame; whatever ends it,
  the status "stopped", empty limit and camera, and the gateway services it started are stopped.
  Every frame and the car's answers go to the trip log (`ADAS parked test …`).
