## BYDMate Waze 4.0.1-dev.11 (development pre-release)

### Fixed
- «Амбієнт у темряві» now turns on the ambient light's master switch, which the car switches off
  between trips (#4). Before it only set the brightness, which the car accepted while the light
  stayed dark. The switch is written on the light device (`LIGHT_ATMOSPHERE_MAIN_SWITCH_SET`, only
  the value «on») and read back; a car without that switch still gets the brightness write. The
  brightness and colour chosen in the car's menu are left as they are.
