## BYDMate Waze 4.2.0-dev.11 (development pre-release)

### Added
- Parked limit change test (#23, the owner's go-ahead of 3.11). On the drive the car took the
  first limit and ignored every later one. The factory map never sends a bare limit: with every
  position it sends the car's place on its route (`sdVehicleLocation`: path, step, link) and
  `TrafficInfo` (limit, road class, distance to the destination).
- How the test runs. In one session it changes the limit 70 → 110 → 70 → 110 every 6 s, in four
  variants of 26 s each:
  1. the limit alone;
  2. the limit plus a route and the car on it, the link going up at each change;
  3. the limit plus the road class and the distance to the destination;
  4. all of the above.
- Every second the test reads what the car shows. Each change and each answer goes to the trip
  log.
- Only in P and standing still; everything is cleared afterwards.
- Settings → «Сервіс і дані» → «Діагностика» → «Тест зміни обмеження (~2 хв)». Keep that screen
  open while it runs.
