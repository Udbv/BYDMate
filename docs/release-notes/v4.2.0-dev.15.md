## BYDMate Waze 4.2.0-dev.15 (development pre-release)

### Changed
- The APK is down from 39.3 MB to 17.7 MB (#65).
  - The voice library and the code are now compressed inside the APK. They used to be stored
    uncompressed: 22.4 MB and 11.2 MB before, 8.2 MB and 5.1 MB now. The cost is unpacking at
    install time.
  - BouncyCastle's unused post-quantum tables (1.2 MB) are gone.
- This is the first step. Next, the voice library, which never changes between builds, moves out
  of the APK into a separate one-time download.
