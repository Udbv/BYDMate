## BYDMate Waze 3.15.0-dev.4 (development pre-release)

**Development channel only.** First build with Waze arrows confirmed on the Tang L glass.

### Confirmed in the car
- The DiLink 150 AR-HUD reads guidance through the instrument-panel features (the channel
  "Guidance to the instrument panel", a port of openbyd's CAN path). With it on, Waze arrows show.

### Fixed
- Switching the HUD projection off (or changing the HUD type) left the last arrow on the glass:
  the instrument features are now reset (navigation status stopped, icon and distance cleared) and
  the factory-map context session is ended.

### Still to check
- Which of the other two channels can stay off ("HUD frame", "Factory-map context").
- Road name on the glass needs a byte-array feature write the helper daemon does not offer yet.
