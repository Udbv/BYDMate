## BYDMate Waze 4.0.1-dev.2 (development pre-release)

Diagnostic files leave the car through the owner's own Telegram bot, no cable or file manager needed.

### Added
- «Дамп FID» goes straight to the linked bot (the share sheet opens only when no bot is linked).
- Trip log: «Надіслати в Telegram» for the newest trip, including the one being recorded, and
  «Надсилати журнал поїздки в Telegram»: the previous trip's log goes to the bot by itself when
  the next trip starts (waits a minute for the modem, retries on network errors, each file once).
- Diagnostic files are pinned silently in the bot chat, so `tools/tg-logs/fetch.py` can collect
  them with the bot token alone and unpin each one it took. Configuration backups are never pinned.

Nothing is sent unless the owner taps or turns the trip toggle on.
