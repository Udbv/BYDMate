## BYDMate Waze 3.15.0-dev.1 (development pre-release)

**Development channel only.** No stable release exists yet: the first stable `main` release will
be cut only after this build has been tested in a real car (BYD Tang L EV 2025).

First release of the Waze-enabled fork, built as a separate app (**BYDMate Waze**, package
`com.bydmate.app.waze`) that installs beside the official BYDMate and updates itself from this
repository's releases.

### New
- **Waze on the factory HUD**, next to Yandex Navigator and Yandex Maps: maneuver, distance, street,
  remaining route and time, speed limit, read from the Waze window through the accessibility service.
  Waze's image-only arrow is classified from a bounded screenshot of the arrow view.
- **Navigator language packs**: Waze instructions in English, Russian, Czech, Chinese and
  **Ukrainian** (incl. roundabout exits and apostrophe variants), units in km/m/mi/ft and
  min/h/хв/год, all in `assets/navi/phrases/<lang>.json`. Adding a language is one file.
- **Ukrainian UI** (Settings -> Language -> Українська).
- **Auto-close of the "This car is not from official export" window** (Settings -> Display,
  off by default): the accessibility service clicks the window's single button.
- **Update channel** (Settings -> Updates): Stable or Development (pre-releases).
- Emulator testbed (dilink5-sim fork): mock SOME/IP gateway, Waze stub, export-warning stand-in.

### Notes
- Target car: BYD Tang L EV 2025 (DiLink 150). The SOME/IP HUD channel on this firmware is not yet
  field-verified; the app reports "SOME/IP bus not found" if the gateway is absent.
- Voice assistant and speech recognition remain Russian.
