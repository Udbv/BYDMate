## BYDMate Waze 4.1.0-dev.24 (development pre-release)

### Changed
- The stable build is clean. A build with `-dev` in its version is a test build: Development
  update channel, and the full trip log, the trip journal sent to Telegram after every drive and
  ADAS shadow mode on by default. The stable build (`X.Y.Z`) defaults to the Stable channel with
  all of those off (each can be switched on in Settings). The flavour used to decide this, so
  the stable 4.1.0-dev.23 behaved like a test build.
- The stable release is called `X.Y.Z` (`v4.1.0`), not `X.Y.Z-dev.N`: it is built from the very
  commit tested in the car, only the name changes (#46).
