## BYDMate Waze 4.2.0-dev.19 (development pre-release)

### Changed
- The dev release build is faster locally: about 10 minutes down to about 4. R8 spent about
  4 minutes on a single ~780-line method, SettingsViewModel.writeDiagnosticHeader. It is now
  split into helpers; the diagnostic dump text is unchanged. The Gradle build cache,
  configuration cache and a 6 GB daemon heap are enabled. The dev release skips lintVital
  (CI lints every push) and now writes its Gradle cache.
