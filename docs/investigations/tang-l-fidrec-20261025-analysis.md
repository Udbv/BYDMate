## 3. Подробиці за ділянками

### 3.1 Динаміка: G-метр, крен, тангаж, рискання

Це найцінніша нова група. Усе в пристрої 1038, значення в `dbl`, `int` = 0.

| сигнал | діапазон у записі | при стоянці (середнє ± σ) |
|---|---|---|
| `ADAS_X_AXIS_ACCELERATION` | −0,42 … +0,33 | +0,012 ± 0,014 |
| `ADAS_Y_AXIS_ACCELERATION` | −0,46 … +0,40 | +0,052 ± 0,021 |
| `ADAS_WX_ROLL_RATE` | −13,8 … +11,4 | σ 0,09 |
| `ADAS_WY_PITCH_RATE` | −13,4 … +15,7 | σ 0,14 |
| `ADAS_WZ_YAW_RATE` | −26,9 … +41,5 | σ 0,09 |

Перевірка на русі:

- X проти dv/dt (швидкість за колесами, згладжено 2 с): r = 0,91 (0,96 після згладжування акселерометра).
  Знак **плюс = розгін**, мінус = гальмування. Піки: +0,330 о 12:34:48 (швидкість 78 км/год, розгін), −0,421 о 12:25:50.
- Одиниці: регресія dv/dt на X дає 7,3 м/с² на одиницю, відношення σ дає 8,6. Обидва нижче 9,81 через шум і запізнення,
  але порядок збігається з **g**. Висновок: «швидше за все g»; точний множник перевірити в машині (різкий розгін з відомим
  часом 0–100).
- Y проти v·ω (ω із `WZ` у град/с, переведена в рад/с): r = 0,88; нахил Y→a_lat 8,06 м/с² на одиницю, знову ближче до g.
- WZ у **град/с**: `Sensor.SENSOR_YAW_RATE_SIGNAL` (1043 / 572523528, в рад/с) відрізняється множником 56,3 (≈ 180/π).
  Максимум 41,5 град/с відповідає 0,69 рад/с.
- Є зсув нуля: на стоянці Y = +0,052. Для G-метра потрібне калібрування «в нуль» при вимкненому русі.
- Знак Y і WZ не прив'язаний до сторони: Y = +0,40 та WZ = +14,2 при куті керма +51,6° (11:55:37), мінус 0,46 при −54,7° (13:49:55).
  Додатний кут керма = додатний yaw = додатний Y. Яка це сторона (ліво/право), у даних не видно; **перевірити в машині**.
- Дубль: `Sensor.SENSOR_AX_223` (1043 / 573571080, int 643–910, центр ~796) з r = 0,94 до X. Масштаб приблизно 0,00264 g на одиницю
  (регресія, здогад), зсув −2,10. Корисний лише як цілочисельний запасний канал.
- Частота 119/хв (тротлінг 500 мс). Для G-метра 2 Гц достатньо для плавного графіка, але не для піків при ударі.

### 3.2 Тяга, потужність по осях, рекуперація

Уже відомі: швидкість і момент моторів (`Engine.ENGINE_FRONT_MOTOR_TORQUE` 1141899288, `ENGINE_REAR_MOTOR_TORQUE_F` 1169162280,
`ENGINE_*_MOTOR_SPEED`). Тут нове — що з ними реально робити.

- **Передній мотор на круїзі.** На трасовому круїзі 75 % відліків мають |момент переду| < 5 Н·м, медіана 0,
  при цьому передній мотор **крутиться завжди** (обороти більше 100 у 100 % відліків: 6453 об/хв при ~100 км/год).
  Тобто він не відключається механічно, лише не дає момент. За інтегралом механічної потужності передній мотор це
  8,5 кВт·год, задній 93,6 кВт·год (≈ 8 % проти 92 %). Максимальний момент: перед +192 / −60 Н·м, зад +421 / −280 Н·м.
- **Масштаб моменту.** `P = M·n·2π/60` для суми осей перевищує електричну потужність: регресія `P_bat ≈ 1,26·P_пер + 0,67·P_зад + 3`.
  Тобто за формулою зад дає завищену потужність приблизно в 1,5 раза порівняно з батареєю. О 12:34:48: зад 387 Н·м × 6273 об/хв = 254 кВт,
  перед 116 Н·м × 5021 об/хв = 61 кВт, разом 315 кВт, а `hv` дає 831 В × 311 А = 258 кВт і `ENGINE_POWER` = 274. Відхилення
  більше за можливий ККД, отже **одиниці або масштаб моменту не Н·м на валу** (невідомо, у чому розрив). Для відносного розподілу
  перед/зад дані придатні; для абсолютних кВт брати батарею. Кореляція `P_мех` з `P_bat` 0,98 без зсуву в часі (лаг +0,5 с дає 0,97).
- **`Engine.ENGINE_POWER`** (є в `FidMap`, `power`): це кВт, ≈ 1,05 × V·I/1000 (r = 0,99). Сторожові значення: 3095 (о 13:54:32 та 14:05:34,
  при вимкненні/пробудженні), інколи 255/254. −1 теж трапляється як реальне значення (рекуперація 1 кВт, 106 разів).
- `Gb.GB_REAR_MOTOR_TARGET_TORQUE` (622854184) практично збігається з заднім моментом (r = 0,998), максимальна різниця 72 Н·м.
- Педаль: `Speed.SPEED_ACCELERATOR_S` (874512392) і `SPEED_VIRTUAL_ACCELERATOR_DEPTH` (606076960) — це **один і той самий** сигнал
  (однакові розподіли, 94 різні значення, макс. 96). Для `FidMap` уже є `pedalAccel`; `VIRTUAL_..` дубль. `SPEED_BRAKE_S` 0–42 (педаль гальма, %),
  `Gearbox.GEARBOX_BRAKE_PEDAL` 0/1/2 (середнє `BRAKE_S` при значеннях 0 / 1 / 2 = 0,1 / 17 / 5 %; зміст значення 2 не встановлено).
  Педаль газу проти заднього моменту r = 0,85.
- **Стан тяги `Energy.ENERGY_STATE`** (1006 / 873463832): подія змінюється 1030 разів.
  Стан 1: швидкість 97 км/год, момент +79 Н·м, потужність +52 кВт, газ 26 %. Стан 4: швидкість 95, момент −69 Н·м, −25 кВт, гальмо 5,6 %.
  Стан 0: швидкість 6 км/год, потужність 0,5 кВт. Отже 1 = тяга, 4 = рекуперація, 0 = нейтраль/стоїть.

- **Фрикційне гальмо.** `ADAS_LFI_LONGITUDINAL_TORQUE_EXECUTION_ESTIMATE` ненульовий лише при натиснутій педалі: 0/−3 без гальма (4620 + 3026 рядків),

## 6. Ідеї для BYDMate (за пріоритетом)

1. **G-метр і оцінка плавності** (#1, #2). Дані вже в безпечному вигляді, лише калібрування нуля (на стоянці) і підтвердження одиниць в машині.
   Додатково показати `WZ` (крен/тангаж не показувати): простий «кружечок» G у режимі водія.
2. **Розбивка потужності: тяга по осях + рекуперація.** Графік потужності (#5) з двох смуг (перед/зад) за відносним моментом; абсолютне значення брати з V·I.
   `ENERGY_STATE` лише для маркування «рекуперація» на графіку. Додати позначку «передній мотор крутиться без моменту» на круїзі (75 % часу).
3. **Витрата без власного інтегрування**: `LAST_50KM_POWER_CONSUME` + три відсотки структури витрати (тяга/клімат/12 В) + лічильники `AFTER_ZEROING`.
   Власне інтегрування V·I підтверджено (збіг 0,3 %), тож може перевіряти внутрішній розрахунок додатка.
4. **Справжня швидкість і проковзування** (#6): `SPEED_AUTO_SPEED_121` і чотири колеса. Прибрати 3 % завищення табло з розрахунку відстані; індикація пробуксовки.
5. **Парк-радар** (#16) тільки як ідея для екрану заднього ходу; дані мовчать на русі.
6. **Фрикційне гальмування** (#4) — за умови з'ясування одиниці LFI. «Скільки гальмування пішло у тепло» як показник.
7. **Якість повітря** (#14): PM2.5 салон/вулиця, просто й безпечно.
8. **ADAS-накладка** (#11–#13): положення в смузі, знак швидкості — тільки після підтвердження значень станів ICA/GRIP та якості знаків.

## 7. Відкриті питання: що перевірити в машині

- [ ] Одиниці `ADAS_X/Y_AXIS_ACCELERATION`: розгін 0–100 з відомим часом або стояти на схилі відомого нахилу. Знак: яка сторона відповідає додатному Y/WZ.
- [ ] Чому `M·n·2π/60` на 30–50 % перевищує електричну потужність (задній момент). Можливо, інша шкала моменту, перевірити по таблиці прошивки або на стенді.
- [ ] Одиниця `ADAS_LFI_LONGITUDINAL_TORQUE_EXECUTION_ESTIMATE`; чи це загальний запит, чи лише фрикційна частина.
- [ ] Значення станів `ADAS_TJA_ICA_STATE` (5 / 1), `ADAS_DRIVER_GRIP_STATUS` (1 / 2), `LEFT_LANE_LINE_TYPE` (0/1/2) — спробувати вмикати/вимикати асистента при записі.
- [ ] Достовірність знаків швидкості; порівняння зі справжніми знаками на трасі.
- [ ] `ENERGY_OPERATION_MODE` 1 ↔ 2 о 12:40:19 / 13:21:21: який режим їзди це був (пов'язаний зі скиданням ADAS-стану).
- [ ] Сутність `STATISTICS_*_CONSUMPTION_50KM` (три відсотки) і `INSTRUMENT_SOC_BALANCE_LOWER_LIMIT`.
- [ ] Прив'язка `PM2P5_VALUE_IN` до одиниць (мкг/м³?) і до режиму рециркуляції.
- [ ] Кривої зарядки в цьому записі немає: потрібен окремий запис під час зарядки (AC і DC) для `CHARGING_*`, `GUN_CONNECT_STATE`, `CHARGE_POWER_DD`, `REST_TIME_DD`.
- [ ] Чи достатньо 2 Гц для G-метра; тротлінг 500 мс це параметр реєстратора, а не обмеження прошивки.
