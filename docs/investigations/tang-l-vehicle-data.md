## Що вже читає BYDMate

Усі адреси моторів з `FidMap` є в каталогі Tang L **з тими самими номерами**, тож на цій машині вони
читаються без переадресації:

| поле FidMap | константа Tang L | номер |
|---|---|---|
| `motorRpmFront` / `motorRpmRear` | `Engine.ENGINE_FRONT_MOTOR_SPEED` / `ENGINE_REAR_MOTOR_SPEED` | 1141899272 / 621805576 |
| `motorCurrentFront` / `motorCurrentRear` | `Charging.CHARGING_DRIVER_MOTOR_CURRENT` / `CHARGING_REAR_DRIVER_MOTOR_CURRENT` | 1186988040 / 1186988056 |
| `motorTempFront` / `motorTempRear` | `Gb.GB_FRONT_MOTOR_TEMP` / `GB_TREAR_MOTOR_TEMP` | 1154482192 / 1155530768 |
| `inverterTempFront` / `inverterTempRear` | `Gb.GB_FRONT_MOTOR_IPM_TEMP` / `GB_REAR_MOTOR_IPM_TEMP` | 1154482184 / 1155530760 |
| `hvVoltage`, `hvCurrent` | `Charging.CHARGING_CHARGE_BATTERY_VOLT`, `CHARGING_CHARGE_CURRENT` | 1145045000, 1145045016 |

`fid=621805576 motorRpmRear=9875`.

## Нове в каталозі: момент по осях

Розподіл тяги перед/зад можна рахувати не тільки зі струму (V × I), а прямо з механічної потужності
кожної осі: **P = M × n × 2π / 60** (M в Н·м, n в об/хв).

| сигнал | константа | пристрій | номер |
|---|---|---|---|
| момент переднього мотора | `Engine.ENGINE_FRONT_MOTOR_TORQUE` | 1012 | 1141899288 |
| момент заднього мотора | `Engine.ENGINE_REAR_MOTOR_TORQUE` | 1012 | 621805592 |
| момент заднього (другий канал) | `Engine.ENGINE_REAR_MOTOR_TORQUE_F` | 1012 | 1169162280 |
| запитаний момент заднього | `Gb.GB_REAR_MOTOR_TARGET_TORQUE` | 1039 | 622854184 |
| загальний момент | `Engine.ENGINE_INDICATED_TORQUE` | 1012 | 283115528 |
| напруга шини переднього / заднього інвертора | `Gb.GB_FRONT_MOTOR_BUS_VOLTAGE` / `GB_REAR_MOTOR_BUS_VOLTAGE` | 1039 | 1169162248 / 1169162264 |
| потужність мотора | `Power.POWER_MOTOR_POWER` | 1005 | 521526 |

Є й моменти по колесах (`Engine.ENGINE_{LEFT,RIGHT}_{FRONT,REAR}_MOTOR_ACTUAL_WHEEL_TORQUE`,
264241256…264241304; `Gb.GB_{LEFT,RIGHT}_FRONT_MOTOR_ACTUAL_TORQUE`, 676331532/676331548).
Ймовірно, це для машин з чотирма моторами (Yangwang): на Tang L, мабуть, порожні. Перевірити дампом.

З 4.0.1-dev.3 діагностичний лог має розділ `--- motors ---`, який читає таблицю вище (лише
читання). Лог, знятий під час розгону, круїзу й рекуперації, покаже одиниці та знак.

## Що перевірити в машині

- [ ] Лог під час розгону, на круїзі, під час рекуперації й на стоянці: одиниці й знак моменту
  (рекуперація від'ємна?), чи нульовий передній момент на круїзі (передній мотор відключається?).
- [ ] Чи збігається сума `P = M × n × 2π / 60` по осях з потужністю батареї `hvVoltage × hvCurrent`
  (різниця — втрати й клімат).
- [ ] Чи дає `motorCurrentFront/Rear` × `hvVoltage` той самий розподіл, що й момент.
- [ ] Частота оновлення: Реєстратор датчиків покаже, як часто змінюється кожен сигнал.

## Ідеї для відображення

- На графіку потужності (#5): дві смуги, перед і зад, замість однієї.
- Позначка «передній мотор вимкнений» на круїзі.
- Втрати на клімат і обігрів батареї: різниця між потужністю батареї і сумою по осях на стоянці
  дорівнює споживанню клімату.
